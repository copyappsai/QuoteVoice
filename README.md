# QuoteVoice 🎙️⚡

> **Instant Voice-to-Quote iOS Mobile Prototype for Trade Contractors**  
> (Electricians, Plumbers, HVAC, Carpenters)

Generate structured, client-ready PDF estimates in 5 seconds just by speaking.

## ✨ Features

1. **Native iPhone 16 Pro Interface**:
   - Realistic titanium chassis with floating Dynamic Island, 5G status bar, and home indicator.
   - Designed for high-converting screen recording promos.

2. **Flow & Capabilities**:
   - **Screen 1 (Home)**: Contractor revenue overview (`$14,250 sent this month`), recent quotes, and glowing blue microphone button.
   - **Screen 2 (Recording & AI)**: 20-band audio visualizer, real-time live transcription with color-coded syntax highlights, and 1.2s snappy AI line item extraction.
   - **Screen 3 (Ready-to-Send Quote)**: Clean invoice preview card for client *John Miller* ($913.00), green *Send via Text / WhatsApp* button with celebratory confetti & toast, plus instant *Download PDF* generation.

3. **Built-in 15s Auto Play Mode**:
   - Single-click automated demonstration timeline for screen recordings.

## 🚀 Quickstart

```bash
# Clone the repository
git clone https://github.com/vargamark11/QuoteVoice.git
cd QuoteVoice

# Install dependencies
npm install

# Start Vite dev server
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/) to view the interactive prototype.
